# Li Bautista Bahjin Security Services Corporation — Website

A responsive one-page company website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main website
- `style.css` — responsive design and layout
- `script.js` — mobile navigation and current year
- `assets/logo.png` — supplied company logo

## How to use
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. To publish it, upload the files to your web host's public web directory.
